# Azure Identity Foundation

## Objectif

Comprendre l'organisation des ressources Azure.

## Concepts étudiés

- Microsoft Entra ID
- Subscription
- Resource Group
- Management Group

## Laboratoire

- [ ] Création de RG DEV
- [ ] Création de RG PROD

## Ce que j'ai appris

- Comprendre la différence entre Active Directory Domain Services et Microsoft Entra ID
- Configurer un suffixe UPN compatible avec Microsoft Entra ID
- Synchroniser une unité d'organisation avec Microsoft Entra Connect
- Différencier Entra Connect Sync et Entra Cloud Sync
- Utiliser Microsoft Graph PowerShell
- Comprendre le Control Plane et le Data Plane
- Documenter une architecture d'identité hybride

## Difficultés rencontrées

- Configuration du domaine vérifié
- Sélection des unités d'organisation à synchroniser
- Résolution des problèmes de suffixe UPN
- Déclenchement manuel de la synchronisation
- Compréhension des différentes sources d'autorité des comptes
