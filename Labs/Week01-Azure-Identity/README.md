# Week 01 - Azure Identity Foundation

## Overview

Week 01 establishes the identity foundation of the Azure Cloud
Architect learning path.

The laboratory connects an on-premises Active Directory environment
to Microsoft Entra ID and introduces cloud identity administration
with Microsoft Graph PowerShell.

## Key Lessons

- Microsoft Entra ID manages cloud identities.
- Azure subscriptions manage resources and billing.
- UPN suffixes should use verified domains.
- Synchronization scope must be controlled.
- Password Hash Synchronization provides resilient cloud authentication.
- Microsoft Graph enables cloud identity automation and auditing.
